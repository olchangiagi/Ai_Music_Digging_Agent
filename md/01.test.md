# 01.test — 초기 설정 및 기본 동작 검증

## 목표

프로젝트의 핵심 능력을 평가할 질문을 정의하고, 개발 환경과 기본 파일 구조를 준비한다. Bedrock 연결과 샘플 음악 데이터의 로딩·검색이 동작하는지 확인한다.

## 수행한 작업

- 핵심 능력 5개에 대한 예시 질문과 성공 기준 정의
- 가상환경 생성 및 `boto3`, `python-dotenv` 설치
- `.env` 설정과 Bedrock 채팅 모델 연결 확인
- 샘플 음악 데이터를 표현하는 `Track` 모델 작성
- JSON 파일을 `Track` 목록으로 변환하는 기능 작성
- 태그의 대소문자를 구분하지 않는 검색 기능 작성
- 검색 결과가 없는 경우 빈 목록을 반환하는지 확인

검증 질문의 전체 내용은 [프로젝트 README](../README.md)에 정리한다. 이 단계에서는 질문을 **정의**했으며, 다섯 질문의 성공 기준을 모두 **검증한 것은 아니다**.

## 주요 파일과 역할

| 파일 | 역할 |
|---|---|
| `app/main.py` | 현재 기능을 연결해 실행하는 진입점과 Bedrock 호출 함수 |
| `app/models.py` | 곡의 제목, 아티스트, 태그를 담는 `Track` 모델 |
| `app/catalog.py` | 샘플 JSON을 읽고 `Track` 목록으로 변환 |
| `app/search.py` | 태그로 곡을 검색 |
| `data/sample_tracks.json` | 기본 기능 확인에 사용하는 샘플 곡 |

## 실행 방법과 결과

프로젝트 루트에서 다음 명령을 실행한다.

```powershell
python -m app.main
```

`dreamy` 태그 검색 결과로 `Midnight City - M83`와 `When the Sun Hits - Slowdive`가 출력되었다. 존재하지 않는 태그를 검색했을 때는 빈 목록 `[]`가 출력되었다.

Bedrock 채팅 모델에 인사말을 요청하는 연결 테스트도 별도로 수행해 정상 응답을 확인했다. 현재 `python -m app.main` 실행에서는 해당 Bedrock 요청을 호출하지 않는다.

## 아직 구현하지 않은 범위

실제 음악 API를 통한 데이터 수집, 데이터베이스 저장, 임베딩 생성, 벡터 검색, LangGraph Agent는 이 단계의 범위에 포함되지 않는다. 핵심 능력 5개에 대한 본격적인 평가는 이후 단계에서 진행한다.
