# 0. 동작 목표 정의
## 핵심 능력과 처리 검증 질문
- 이 프로젝트의 목표는 익숙한 음악에서 새로운 음악으로 탐색을 넓히고, 구체적인 취향 조건에 맞는 곡을 근거와 함께 제안하는 것을 목표로 정함
- 아래 질문은 초기 개발 단계에서 기능을 확인하기 위해 설정한 예시 사례, 구현하며 조정 예정

|핵심 능력|예시 질문|성공 기준|
|---|---|---|
|취향에서 탐색 확장|The Weekend와 비슷한 분위기의 덜 알려진 다른 아티스트의 곡을 찾아줘.|제시한 취향과의 연결점을 설명하고, 요청한 아티스트의 곡만 반복 추천하지 않음.|
|복합 취향 이해|2000년대 이후 일본 슈게이즈 중 시끄럽고 기타 소리가 부각되는 곡을 찾아줘|시대, 지역, 장르, 분위기 등 제시된 조건을 동시에 고려.|
|제외 조건 준수|류이치 사카모토의 곡 중 영화 OST에 사용된 곡은 제외하고 검색해줘.|제외 조건을 지키면서 대안 곡을 제시.|
|근거 있는 설명|드럼&베이스 곡을 추천하고, 각 곡이 해당 장르 입문곡으로 적합한 이유를 설명해줘.|실재하는 곡을 제시하고, 확인 가능한 곡 정보에 근거해 설명함.|
|정보 부족 시 대응|2000년 이전 한국 여성 보컬 매스 록 곡을 찾아줘.|조건에 맞는 곡을 찾이 못하면 임의적으로 만들어내지 않고, 부족한 조건을 알리거나 탐색 범위 제안.|
