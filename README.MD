# AI Music Digging Agent

## 프로젝트 소개

AI Music Digging Agent는 익숙한 음악에서 출발해 새로운 곡과 아티스트를 탐색하도록 돕는 프로젝트다. 사용자의 취향과 조건을 이해하고, 추천한 음악의 근거를 설명하는 것을 목표로 한다.

## 핵심 능력과 검증 질문

아래 질문은 구현 과정에서 기능을 평가하기 위해 정의한 사례다. 아직 모든 질문에 대한 평가를 완료한 것은 아니다.

| 핵심 능력 | 예시 질문 | 성공 기준 |
|---|---|---|
| 취향에서 탐색 확장 | The Weeknd와 비슷한 분위기의 덜 알려진 다른 아티스트의 곡을 찾아줘. | 취향과의 연결점을 설명하고, 요청한 아티스트의 곡만 반복 추천하지 않는다. |
| 복합 취향 이해 | 2000년대 이후 일본 슈게이즈 중 시끄럽고 기타 소리가 부각되는 곡을 찾아줘. | 시대, 지역, 장르, 분위기 등의 조건을 함께 고려한다. |
| 제외 조건 준수 | 류이치 사카모토의 곡 중 영화 사운드트랙에 사용된 곡은 제외하고 검색해줘. | 제외 조건을 지키면서 대안 곡을 제시한다. |
| 근거 있는 설명 | 드럼&베이스 곡을 추천하고, 각 곡이 해당 장르 입문곡으로 적합한 이유를 설명해줘. | 실재하는 곡을 제시하고 확인 가능한 정보에 근거해 설명한다. |
| 정보 부족 시 대응 | 2000년 이전 한국 여성 보컬 매스 록 곡을 찾아줘. | 조건에 맞는 곡을 찾지 못하면 임의로 만들어내지 않고 탐색 범위 조정을 제안한다. |

## 기술 구성

- 현재 확인한 기능: Amazon Bedrock 연결, 샘플 JSON 로딩, 태그 검색
- 이후 구현할 기능: 외부 음악 데이터 수집, PostgreSQL+pgvector, LangGraph Agent, Apache Airflow 파이프라인, FastAPI
- 비용 절감 방향: 데이터베이스와 Airflow는 우선 로컬 Docker에서 운영하고, AWS는 Bedrock과 S3를 중심으로 사용한다.

위 목록의 “이후 구현할 기능”은 현재 동작하는 기능을 뜻하지 않는다.

## 시작하기

프로젝트 루트에서 가상환경을 활성화하고 패키지를 설치한다.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

`.env`에는 `AWS_REGION`, `BEDROCK_CHAT_MODEL`, `BEDROCK_EMBED_MODEL`, `AWS_BEARER_TOKEN_BEDROCK`을 설정한다. 실제 토큰 값은 문서나 Git에 기록하지 않는다. 현재 임베딩 모델 설정은 아직 검색 기능에 사용하지 않는다.

현재 샘플 데이터 검색은 다음 명령으로 실행한다.

```powershell
python -m app.main
```
